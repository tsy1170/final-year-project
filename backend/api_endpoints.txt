PriceCatcher Backend API Endpoints
=================================
✅ - Implemented

GET /
- Root endpoint
- Returns server status message

GET /products/categories ✅
- Get all product groups and categories

GET /products/{item_code}/nearby-price-levels ✅
- Get nearby store prices for a product with price levels
- Parameters:
  - item_code: int
  - latitude: float
  - longitude: float
  - radius_km: float

GET /products/search ✅
- Search products by name
- Parameters:
  - q: str

GET /products
- Get products with optional filters and pagination
- Parameters:
  - item_group: str | None
  - item_category: str | None
  - limit: int
  - offset: int

POST /users/register ✅
- Register a new user
- Parameters:
  - user: UserRegister object

POST /users/login ✅
- Log in and receive a JWT access token
- Parameters:
  - username: str (email)
  - password: str

GET /users/me ✅
- Get the currently authenticated user's information
- Authorization: Bearer token required

POST /favourites ✅
- Add a product to the authenticated user's favourites
- Authorization: Bearer token required
- Parameters:
  - request_data: FavouriteItem object

GET /favourites ✅
- Get the authenticated user's favourite products
- Authorization: Bearer token required

DELETE /favourites/{item_code} ✅
- Remove a product from the authenticated user's favourites
- Authorization: Bearer token required
- Parameters:
  - item_code: int

POST /favourites/optimize/single-store 
- Optimize basket for a single store
- Parameters:
  - request_data: BasketOptimizationInput object

POST /favourites/optimize/multi-store 
- Optimize basket across multiple stores
- Parameters:
  - request_data: BasketOptimizationInput object
